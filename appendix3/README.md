# 부록 3. 적합 질의와 실행 결과

[English](README.en.md) | **한국어**

적합 질의 Q1~Q7은 [부록 2](../appendix2/README.md)의 명시된 인스턴스 트리플을 대상으로 실행하였습니다. 질의는 SPARQL 1.1 구문을 사용하며, 결과는 **추론 전 그래프**에 대한 반환값입니다.

## 실행 환경

| 항목 | 내용 |
|---|---|
| 기준 어휘 | RiC-O 1.1 (2025-05-22) |
| 데이터 | 280트리플 / RiC-O 클래스 14종 / 프로퍼티 18종 |
| 질의 실행 | Python 3.12 / RDFLib 7.6.0 / SPARQL 1.1 |
| 질의별 반환 행 | Q1 3행 · Q2 2행 · Q3 9행 · Q4 2행 · Q5 1행 · Q6 1행 · Q7 7행 |

논문에서는 구문 분석과 어휘 대조를 수행하고 일곱 질의의 반환 결과를 확인하였습니다. OWL RL 규칙 추론 검사는 RiC-O와 사례 데이터를 병합하여 명시적 클래스 상호 배타성 충돌을 점검한 것으로, **OWL DL 전체 일관성 검증과 구분**됩니다.

## 구성

- [`queries/`](queries/) — 질의문(`.rq`)
- [`results/`](results/) — 실행 결과(CSV, UTF-8 BOM)
- [`run_queries.py`](run_queries.py) — 재실행 스크립트

```bash
pip install rdflib
python appendix3/run_queries.py
```
